# MT6252 固件模拟器

AI+Rust重写

## 目录结构

```
src/
├── main.rs            两条线程：仿真线程独占 Unicorn，UI 线程只管窗口
├── config.rs          芯片级常量、中断周期、镜像文件查找
├── profile.rs         固件画像的 schema 与加载（按 ROM CRC32 匹配）
├── engine.rs          uc_engine 裸句柄封装（hook 回调里要用它读写 guest 内存和寄存器）
├── memmap.rs          物理地址布局 + 各外设寄存器表（数据手册镜像，允许有未接线的位段）
├── events.rs          VmEvent 与中断线编号
├── frame.rs           Arc<Mutex<Frame>>，UI 用 serial 判断要不要重绘
├── ui.rs              winit 事件 + softbuffer 提交
├── pad.rs             屏下虚拟按键面板：布局、5x7 点阵、鼠标命中测试
├── vm/
│   ├── mod.rs         Vm 聚合根、建映射、装固件、主循环（时间片 + 心跳 + 卡死现场转储）
│   ├── mmio.rs        MMIO 读写分派、MSDC 命令与 DMA 搬运
│   ├── interrupt.rs   中断注入、哨兵返回、上下文保存恢复
│   └── patch.rs       固件补丁表（对应 C 版 hookCodeCallBack 的那些 case）
├── devices/           lcd / keypad / dma / irqc / rtc / sd / sim / sfi / c1xx / l1_win
└── ...
profiles/ihd316.toml   IHD 316 这份固件的画像
tools/make_sd_image.py 生成结构合法的 FAT32 SD 镜像
tools/scan_lit.py      扫镜像里能覆盖到某个 RAM 块的基址字面量（找"谁在写这块"用）
tools/find_bl.py       反向找"谁 BL 到这个函数"（Thumb-2 BL/BLX.W + ARM BL + 文字池桩）
```

## 调试开关

| 环境变量 | 作用 |
|---|---|
| `MT6252_TRACE=1` | 打印中断控制器/C1XX 的掩码变更、每次中断注入与返回、MMIO 读计数 `[poll]`、自旋处指令字节 `[code]` |
| `MT6252_TRACE_BLOCKS=1` | 额外挂全地址空间块级 hook（很慢），卡死时打印最近执行过的基本块 |
| `MT6252_NO_IRQ=1` | 完全不注入中断，用来判断"是 ISR 把状态搞坏了还是别的" |
| `MT6252_MODESWITCH=1` | 按硬件语义切到 IRQ 模式再写 SPSR/LR/SP；不设则退回 C 版的偷懒做法 |
| `MT6252_PROFILE=<file>` | 强制使用某份画像，跳过 CRC 匹配 |
| `MT6252_ROM=<file>` | 指定固件镜像 |
| `MT6252_LIST_PATCHES=1` | 启动时把画像里的补丁/预置/读回覆盖逐条打印 |
| `MT6252_WATCH=0x4000b210:4` | 监视 guest 地址被谁写（打印写入 PC） |
| `MT6252_DUMP=0x081a1500:800` | 卡住时把区间导出到 `dump/`，喂给反汇编器 |
| `MT6252_MAX_SLICES=13000` | 跑满这么多**指令片**就自己收工。**别用外部 `timeout`**：Git Bash 下 `timeout -s KILL` 只杀 `timeout.exe`，guest 变孤儿继续抢 CPU；而且按墙钟截止会让轨迹不可复现 |
| `MT6252_PROBES=none` | 只装画像里的行为补丁、一颗探针都不挂。不设 = 全装（494 条 → ~5 片/秒 vs 16 条 → 119~201 片/秒，**深跑先设 none**）。也可以给逗号分隔的标签子串来只留几条 |
| `MT6252_FP=250` | 每 250 片打一行**轨迹指纹**（片边界 PC / CPSR / **SP** / 当前任务 TCB / 四个中断累计计数 / 三段 RAM 的 FNV 摘要），用来做改动前后的可复现性校验。`sp=` 与 `任务=` 是 2026-09-27 为 #46 加的：SP 落进 `[任务, 任务+0xb4)` 时另起一行 `[spalert]`（**不塞进 `[fp]`**，那行是逐行 diff 的基线）。⚠ 加了这两个字段之后，**旧日志的 `[fp]` 行与新日志不能整行对比**，只能比公共字段。**不要用 `[tick]` 当指纹** —— 那是墙钟 2 秒心跳，同一份二进制跑两轮行数和行内容都不一样 |
| `MT6252_ZEROS=1` | `[count]` 行除了命中的标签，还把**这一轮装上了但一次没命中**的 `count` 探针列成 `标签=0`。默认不开：全探针画像下 500 多个标签，每两秒一行会被零撑爆。用途是把"缺席"变成读数——判断"某条链一次没进"时，没有这一项只能靠推断，而"探针被 `MT6252_PROBES` 筛掉了"和"固件没走到这里"在旧版报告里长得一模一样 |
| `MT6252_RTC=host` | 让待机时钟跟宿主机当前时间走。默认是常量起点 `2026-09-27 00:00`，因为"这一轮跑在几点"是仿真输入里唯一每轮都变的量，会把 RAM 摘要带偏（详见 `devices/rtc.rs`） |
| `MT6252_RUN_TAG=<名>` | 给 `MT6252_DUMP` 的文件名加轮次标记。不设会退化成 Unix 秒数；**同一轮内多次采样必须同 tag**，否则后一次静默覆盖前一次，"显存被清零"就是这么误判出来的 |
| `MT6252_KEYS=11500:q,12600:d@12800` | 按**片**触发的按键脚本，走 `Vm::handle_event` 真入口（和窗口敲键盘同一条路，不是旁路）。键名同窗口映射 `0-9 q e w a s d f z c n m`；`@松开片` 覆盖默认按住时长。**按住时长必须 ≥ 几百片**：50 ms 的按压这份固件不当它是按键，见「第十续」 |
| `MT6252_FB_PNG=dump/host` | 主机合成器每出一帧就往该目录写 `host_f<帧号>_s<片>.png`。**判断"屏幕上有没有东西"只认这个**，显存 dump 要人自己叠层，会把图层读反 |
